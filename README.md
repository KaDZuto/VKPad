# 🎵 VKPad — Нативный VK & VK Музыка для iOS 10.3 (iPad mini 2)

**VKPad** — легкий, нативный клиент для социальной сети **ВКонтакте** и **VK Музыки**, оптимизированный для старых iPad (iOS 10.3.3, ARM64 / процессор Apple A7).

Приложение разработано на нативном Objective-C / UIKit с поддержкой непрерывного фонового воспроизведения музыки, управления на экране блокировки (`MPNowPlayingInfoCenter`) и без ограничений по времени прослушивания.

---

## 🎧 Возможности

- **VK Музыка:**
  - Доступ к разделу **«Мои аудиозаписи»** (весь ваш сохраненный список треков).
  - Раздел **«Рекомендации»** от алгоритмов VK.
  - Мгновенный **поиск по всей базе музыки VK** (по названию трека или имени артиста).
  - Встроенный мини-плеер внизу экрана: кнопки Назад / Пауза / Вперед, название трека и исполнитель.
  - Полноценное **фоновое воспроизведение** (`UIBackgroundModes: audio`): музыка продолжает играть при блокировке экрана или сворачивании приложения.
  - Нативное управление в **Пункте управления** и на **экране блокировки** iOS.
- **Новости (Лента VK):**
  - Просмотр постов, записей групп и новостей друзей.
- **Два способа авторизации:**
  - Вход через встроенный браузерный OAuth прямо на iPad.
  - Ручной ввод токена Kate Mobile / VK Admin для прямого доступа без ограничений.

## 🔑 Подробный гайд: Как получить токен Kate Mobile для доступа к музыке

Официальное API ВКонтакте ограничивает доступ к разделу музыки для обычных приложений, однако клиенты вроде **Kate Mobile** имеют официальные права на аудиопотоки без блокировок.

### Способ 1: Получение через сервис VKHost (Самый простой способ)

1. Откройте в любом браузере на ПК, смартфоне или самом iPad сайт:
   👉 **[https://vkhost.github.io](https://vkhost.github.io)**
2. В списке приложений выберите **Kate Mobile** и нажмите кнопку **«Настройки» / «Получить»**.
3. Откроется официальная страница авторизации `oauth.vk.com`. Нажмите **«Разрешить»** доступ (к аудио, друзьям, стене и офлайн-режиму).
4. После подтверждения браузер перенаправит вас на пустую страницу (`blank.html`).
5. Посмотрите на адресную строку вашего браузера. Она будет выглядеть примерно так:
   ```text
   https://oauth.vk.com/blank.html#access_token=vk1.a.XXXXX...XXXXX&expires_in=0&user_id=12345678
   ```
6. Скопируйте значение после `access_token=` и до знака `&` (сам длинный ключ).
7. В **VKPad** на вкладке **«Настройки / Вход»** нажмите **«Ввести Kate Mobile токен вручную»**, вставьте этот ключ и нажмите **«Сохранить токен и войти»**.

### Способ 2: Прямая ссылка авторизации (В браузере)

Вы можете сразу открыть готовую ссылку для выдачи токена приложения Kate Mobile:
```text
https://oauth.vk.com/authorize?client_id=2685278&scope=audio,wall,friends,messages,offline&redirect_uri=https://oauth.vk.com/blank.html&display=touch&response_type=token&v=5.131
```
После авторизации скопируйте `access_token` из адресной строки и вставьте в приложение.

## 🛠 Руководство по установке на iPad

### Установка готового IPA:
1. Скачайте `VKPad.ipa` из вкладки **Releases**.
2. Установите через **Sideloadly**, **AltStore** или через SSH:
   ```bash
   iproxy 2222 22
   scp -P 2222 VKPad.ipa root@localhost:/tmp/
   ssh -p 2222 root@localhost "unzip -o /tmp/VKPad.ipa -d /tmp/vk && \
                               cp -r /tmp/vk/Payload/VKPad.app /Applications/ && \
                               ldid -S /Applications/VKPad.app/VKPad && \
                               chown -R root:wheel /Applications/VKPad.app && \
                               uicache"
   ```
